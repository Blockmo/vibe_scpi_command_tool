# All-In-One 整合程式

單一視窗整合所有儀器的 SCPI 控制面板。

```bash
cd All-In-One
python all_in_one.py
```

## 介面

- **左上角下拉式選單**：先選「分類」，再選該分類下的「儀器」
- **右上角**：Language（英文 / 繁體中文，預設英文）
- **底部狀態列**：目前已連線的儀器清單
- **Copy Command**：複製目前所選指令的完整 SCPI 字串（含參數、通道），不需連線

| 分類 | 儀器 |
|------|------|
| Power Supply 電源供應器 | 2231A-30-3 / E3633A / E36300 / Chroma 62000P |
| DAQ 資料擷取 | DAQ973A |
| E-Load 電子負載 | Chroma 63600 |
| Oscilloscope 示波器 | DPO 7 Series / MSO 5 Series / R&S RTE |
| Function Generator 函數信號產生器 | AFG3000 / AFG31000 |
| Meter / SMU 電錶 / 電源量測單元 | Series 2400 |

切換儀器時，原面板會**保留在背景**（連線、選擇、紀錄都不會遺失），因此可以同時連線多台儀器並輪流操作。關閉視窗時會自動中斷所有連線。

每台面板的連線列有「Scan」（列出 VISA 資源，GPIB 優先並附 `*IDN?`，由下拉選擇）；指令區有「Search」關鍵字篩選（空白分隔多個關鍵字、可與群組並用、Esc 清除）。

模擬模式已自介面隱藏，開發測試請用 `python all_in_one.py --sim`。

## 運作方式

本程式**不複製**任何指令資料：選到某台儀器時，才從其原資料夾（`../<folder>/`）動態載入該台的指令資料表與驅動類別，再交給通用面板顯示。因此修改各台的 `_specs/` 或指令資料表後，整合程式會自動使用新資料。

通用面板支援兩種通道模型：

- **通道清單型**（2231A / E3633A / E36300 / Chroma 62000P / DAQ973A / Chroma 63600）：`(@通道清單)` 欄位
- **標頭編號型**（AFG3000 / AFG31000 / DPO7 / MSO5）：通道 `{ch}`、編號 `{n}` 欄位

新增儀器：在 `all_in_one.py` 的 `INSTRUMENTS` 加一筆設定，並放進 `CATEGORIES` 的某個分類即可。

| 檔案 | 用途 |
|------|------|
| `all_in_one.py` | 主程式（儀器登錄表、動態載入、通用面板、主視窗） |
| `i18n.py` | 介面文字翻譯表（英文 / 繁體中文） |
